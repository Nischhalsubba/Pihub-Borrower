# PiHub Borrower

Standalone PiHub Borrower / origination application.

This repository is being extracted from `Nischhalsubba/Pihub-Investor` so Borrower can build, test, deploy, and roll back independently.

The initial extraction preserves the current production-tested Borrower UI and temporarily vendors the shared PiHub UI/platform source required by the application. Those shared sources can move to a dedicated versioned PiHub Platform package repository later without coupling Borrower back to Investor.
